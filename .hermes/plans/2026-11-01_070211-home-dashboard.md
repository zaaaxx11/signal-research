## Goal

Replace the two-column signal grid with the dashboard the operator described — headline bar, index and spark strips, breadth tiles, a 2:1 movers/map pair, a signal block, and an insider strip — fed by one request, inside a header that carries brand, search, nav and a day/night switch.

## Architecture

One new aggregate endpoint, `GET /market/home`, composes the documents above server-side and returns a trimmed payload (~45 KB) so the page paints from a single request. The header stays a shell concern: a `HeaderBar` that can collapse, a `ThemeToggle` that writes `data-theme` on `<html>`, and a persisted preference. Motion is CSS-only (no animation library), gated by the existing `prefers-reduced-motion` rule in `web/src/styles/index.css`.

## Task 3 — `GET /market/home` (the aggregate)

**Files:** new `app/api/home.py`, tests `tests/test_api_market_home.py`, registration in `app/main.py`.

```jsonc
{
  "as_of": "…",
  "indices": [{"symbol":"^GSPC","label":"S&P 500","price":7580.07,"change_pct":-1.82,"closes":[7590.1,…]}],
  "breadth": {"universe":5576,"advancing":1557,"declining":3932,"unchanged":189,
              "new_highs":45,"new_lows":54,"above_50":2104,"below_50":3472},
  "sparks":  [{"symbol":"AAPL","name":"Apple Inc.","price":344.63,"change_pct":-1.23,"volume":42421212,"closes":[…30]}],
  "movers":  {"gainers":[…],"new_high":[…],"overbought":[…],"new_low":[…]},   // ≤ 40 rows total
  "map":     {"sectors":[{"id":"Finance","value":-0.48,"symbols":[{"s":"AAPL","c":5034.7,"v":-1.23}]}]}, // top 600 tiles
  "news":    [{"headline":"…","url":"…","source":"…","published_at":"…"}],       // 3
  "filings": [{"symbol":"AAPL","owner":"Newstead Jennifer","role":"…","filed":"2026-10-29"}], // 5
  "method":  "…"
}
```

Rules:

* **One pass** over the selector's universe for breadth, movers and `above_50` (reuse `app/api/sectors.py`'s tally if it already does this; do not scan per block).
* Indices and sparks reuse the chart reader from `app/api/chart.py` (import the module's fetch/cache helper, do not duplicate the parser) with a 60 s cache and `X-Home-Cache`.
* The map block is `/market/map` **truncated to the 600 largest tiles**; the document says `"tiles": 600, "tiles_total": 5573` so the page can print "600 of 5,573".
* A block whose source fails is `null` with its name in `"unavailable": ["filings"]` — never an empty list that reads as "nothing happened".
* Weak ETag over `(scan generation, depth identity, news bucket, index bucket)`, `304` before any work, `HEAD` as its own route.
* Payload budget: **≤ 60 KB raw**; assert the serialised length in a test.

Block contracts (each is a card, `data-testid="home-<name>"`):

1. `HeadlineBar` — the newest headline as a link, `HH:MM · 31 Oct 2026 · SOURCE`, `target=_blank rel="noopener noreferrer"`. One line, truncates; if news is unavailable it says "Headlines unavailable" rather than showing nothing.

3. `BreadthTiles` — six tiles, each a number and a label; above/below 50-day are computed server-side; a tile whose value is `null` prints "—" and a title saying why.
4. `MoversBlock` (left, 8/12) — up to 40 rows from four groups, each row: logo, symbol, price, change, and a group chip (`Top gainers`, `New high`, `Overbought`, `New low`); sorted by group then value; a "see all" link to `/screener`.
5. `MiniMap` (right, 4/12) — the existing canvas renderer with `variant="compact"`: no sidebar, no legend list, hover popup kept, click opens `/stock/{symbol}`. Extracted from `MapPage` so there is one layout engine, not two.
6. `SignalsBlock`, `HeadlinesBlock`, `MajorsBlock` — the three small boxes: signal counts from `/market/signals` groups, the news list (5 rows), and "major" = the two index-fund headlines (SPY/QQQ) separated from the rest.
7. `InsiderStrip` — five Form 4 rows: `filed`, `symbol`, `owner`, `role`; the strip's caption says "Latest Form 4 filings" and links to `/insider`. If `filings` is unavailable the strip says so and links to `/insider` anyway.
8. `HomeFooter` — a 32 px bar, `ztockz`, muted, no links, no version, no timestamps.

## Task 5 — Motion and events (what "adds experience" without adding noise)

Every item is CSS or a DOM event; no animation library. All of it is inside the existing `@media (prefers-reduced-motion: reduce) { * { animation: none; transition-duration: 0.01ms } }` rule, so it disappears for anyone who asks.

| Where | Motion | Duration | Why |
|---|---|---|---|
| Route change | content fades 0 → 1 and lifts 4 px → 0 | 140 ms ease-out | the page was a hard cut; a short settle says "new view" without a spinner |
| Cards on first paint | opacity 0 → 1, 8 px up, staggered 20 ms per card, capped at 8 cards | 180 ms | a dashboard assembling, not a slot machine |
| Sparkline | line draws left→right via `stroke-dashoffset` | 320 ms once | the strip reads as data arriving |
| Quote tick | the number flashes its own tone (`bg-up/10` → transparent) | 400 ms | a changed price is visible without moving the layout |
| Hover on a tile/card | `translateY(-1px)`, border `--line` → `--line-strong` | 120 ms | a surface that responds to the pointer |
| Nav toggle | panel height via `grid-template-rows: 0fr → 1fr` | 160 ms | no measured height, no jump |
| Theme switch | 120 ms cross-fade of `background-color`/`color` on `body` only | 120 ms | a switch should feel like a switch, not a flash-bang |
| News day header | `position: sticky` with a 1 px shadow once stuck | — | the day stays readable while scrolling |
| Table row keyboard focus | the existing ring, no motion | — | focus must never animate |

Events to wire (and test):

* `⌘K` / `Ctrl-K` opens the symbol search (already exists for `/`), `Escape` closes it.
* Clicking a headline opens a new tab; middle-click works because it is a real `<a>`.
* Clicking a movers row opens `/stock/{symbol}`; Enter on a focused row does the same.
* Clicking a map tile opens `/stock/{symbol}`; the popup follows the pointer and never blocks it (`pointer-events: none`).
* The theme button announces the change through a `role="status"` sentence ("Light theme on").
* On `visibilitychange` returning to the tab, Home revalidates with `If-None-Match` (304 costs 1 ms, so a tab left open overnight is not stale).

## Risks and open questions

* **One big endpoint vs six small ones.** `/market/home` is ~45 KB and one round trip; six endpoints would be ~200 KB and six round trips. The aggregate wins on first paint but couples the blocks: a failure in one block must degrade to `null`, never to a 500. The tests above pin that.
* **The map on Home is a second consumer of the treemap engine.** Extract, do not copy: `MiniMap` and `MapPage` must share `layoutMap`/`paintChart` from `web/src/map/`.
* **Light theme is a design decision, not a toggle.** The accent must darken (#c2185b) to stay legible on white; the pink-on-pink trap the token file warns about gets worse in light mode, so `--down` moves to `#b3261e`.
* **Indices are Yahoo meta, not an exchange feed.** Delayed quotes; the strip labels them "Delayed" once, quietly, in the footer of the strip (not a badge per card).
* **Index universes (S&P 500 / Dow in the screener) are a separate wave.** `index_membership` covers 2,744 of 4,217 depth rows (S&P 500 480, DJIA 30, NDX 90, Russell 2000 1,872). Adding them as screener presets needs a filter that reads a depth-derived column — plan it after Home.
* **Open:** does the operator want the headline bar to rotate through the top three stories every 6 s, or stay on the newest? The plan assumes **stays** (rotation is motion without information, and it fights reading).
