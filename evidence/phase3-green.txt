## 7. Honest gaps (unchanged from RED, not hidden)

1. **Resume is proved by batch status, not by artifact backing.** 02 §3.5 wants a
   `Success` batch skipped only when its artifact still backs every row. Per-batch
   artifact naming is not part of the export contract yet (kind = format), so
   inventing it now would freeze an unagreed convention. This remains a Fase 5
   item (`14-phase3-red.md` §3.2).
2. **Per-phase deadline is still untested.** `phase_reports` carries
   `skipped_by_budget`, but there is no injectable clock/deadline contract for a
   phase yet; the cross-rung budget is already covered by Fase 2.
3. **`verify` reports `partial`.** `verified_columns_count` stays `0` because
   V1..V16 are Fase 4. Reporting `filled == verified` would be a fabricated
   verification claim.
4. **`eod`/`performance`/`fundamentals`/`options` report `skipped`.** The phases
   are declared, ordered and reported, but no adapter is wired into the worker
   for those capabilities yet. A phase that did not run does not report `ok`.
